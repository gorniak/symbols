# Electronics symbols

Based on IEC 60617 and IEEE Std 315-1975 (ANSI Y32.2-1975).

52 symbols, each as **SVG** (vector, mm units), **PNG** (2400 dpi, white background) and **draw.io** (one shape with connection points at the lead ends).

Open `index.html` for a visual overview.
